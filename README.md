# RoyalStay Intelligence website

The public website and live sample for RoyalStay Intelligence. It is plain files with no server, published free on GitHub Pages:
https://mrandrecloete-hub.github.io/royalstay-website/

The Sign in and Register buttons go to the app at https://royaltystay.abrdns.com. The app itself is a separate private project.
To publish a change, edit the files and push to `main`. GitHub Pages updates in about two minutes.
